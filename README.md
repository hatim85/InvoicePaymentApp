# InvoicePaymentApp

InvoicePaymentApp is a decentralized application (dApp) built using **JavaScript** and **Solidity**. It provides a platform for creating, managing, and paying invoices on the blockchain, ensuring transparency and trust between parties.

## Features

- **Invoice Management**: Create, view, and manage invoices easily.
- **Blockchain Integration**: Leverages blockchain technology for secure and immutable transactions.
- **Payment Processing**: Pay invoices directly through the app using cryptocurrency.
- **Smart Contracts**: Utilizes Solidity smart contracts to enforce payment rules and automate processes.
